# 数学小游戏说明文档

## 一、这个作品是做什么的

这个作品里面有三个数学小游戏，分别是“极速圆周率”“调味师大挑战”和“趣味数学闯关”。

我做这些游戏，是想让数学练习不要只有写题。因为有时候一直做练习册会有点枯燥，所以我想把数学知识放到游戏里面，让同学们一边玩一边复习。

这三个游戏练习的内容不太一样。“极速圆周率”主要练圆的知识，“调味师大挑战”主要练比例、百分数和分数，“趣味数学闯关”主要是综合题目练习。

## 二、创意来源

这个作品的想法主要来自平时学习数学的时候。很多同学其实知道公式，也知道老师讲过什么，但是一到做题的时候就容易算错，或者把半径、直径、比例、百分数这些弄混。

所以我想做几个比较有趣的小游戏，让同学们在游戏里多练几遍。这样既可以巩固知识，也不会觉得只是一直写题。

“极速圆周率”是因为圆的周长、半径、直径这些公式很容易混，所以做成一个需要快速判断的游戏。

“调味师大挑战”是把比例和百分数放到调饮料里面。因为饮料有多少果汁、多少水、多少糖浆，比较容易看出部分和整体的关系。

“趣味数学闯关”就是一个题库闯关游戏，里面可以放很多种数学题。这个题库我还在继续改，想尽量多放一些知识点。

## 三、实现过程

这个作品是用网页技术做的，主要用了 React、TypeScript、Vite 和 Ant Design。

React 用来做页面和按钮交互。比如点击开始游戏、选择答案、输入数字、显示分数这些，都是用 React 来控制的。

TypeScript 用来让代码更清楚。比如一道题有什么选项、答案是什么、难度是什么、属于哪个知识点，都可以写成固定的格式，这样后面加题的时候不容易乱。

Vite 用来运行和打包项目。Ant Design 用来做一些按钮、弹窗、选择框和进度条，让页面看起来更整齐。

三个游戏的代码是分开写的。这样一个游戏改动的时候，不会影响到另一个游戏。比如“极速圆周率”有自己的计算规则，“调味师大挑战”有自己的订单和配方，“趣味数学闯关”有自己的题库和答题规则。

“趣味数学闯关”后来还加了联机功能。这个功能用了 WebSocket。简单来说，就是几个人可以一起进入同一个房间，然后一起答题。服务器会负责同步房间、玩家、题目、分数和最后的排名。

## 四、三个游戏介绍

### 1. 极速圆周率

这个游戏主要练习圆的知识。

游戏会给出半径、直径或者面积之类的信息，然后玩家要判断哪个圆周长是正确的。玩家需要快速移动到正确答案的位置。

这个游戏可以帮助同学复习：

- 圆周长公式
- 半径和直径的关系
- 面积和半径的关系
- 怎么把公式代进去计算

如果选错了，游戏会显示正确的计算过程。这样就能知道自己错在哪里，比如是把半径当成直径了，还是公式用错了。

### 2. 调味师大挑战

这个游戏是一个调饮料的小游戏。

玩家会看到顾客的要求，比如果汁和水的比例是多少，或者糖浆占整杯的百分之多少。然后玩家要选择原料，用不同容量的量杯倒进杯子里。

这个游戏主要练习：

- 比例
- 百分数
- 分数
- 总量和部分量的关系

我觉得这个游戏比较直观，因为杯子里面不同颜色的液体可以看出每种原料大概有多少。提交以后，游戏会告诉玩家准确度，也会显示正确配方。

### 3. 趣味数学闯关

这个游戏是一个综合题库。

题目有单选题、多选题和填空题。每道题都有时间限制，答对加分，答错或者超时会扣分。

现在这个游戏加了题目筛选功能。开始之前可以选择想练的知识点，也可以选择难度，比如基础、进阶、挑战。这样如果只想练某一类题，就不用把所有题都做一遍。

这个游戏也加了多人联机功能。玩家可以创建房间，也可以输入五位房间号加入别人的房间。房主可以选择题目的知识点和难度，大家准备好以后就一起开始答题。

联机的时候，每个人都有自己的分数。答题页面也会显示其他人有没有提交。全部在线玩家都提交以后，就会进入下一题。最后游戏会显示排名。

目前题库已经有比例、比例尺、正比例、反比例、圆柱圆锥、图形运动、放大与缩小、综合计算等内容。不过题库还在继续修改，我想后面再加更多题。

## 五、创新点

### 1. 不是普通做题

这三个游戏不是直接把题目列出来让人做，而是把题目变成了游戏任务。

比如圆的知识变成了快速选择圆环，比例和百分数变成了调饮料，综合练习变成了闯关。

### 2. 更容易看懂数学关系

有些数学知识比较抽象，但是做成游戏以后会更好理解。

比如调饮料的时候，杯子里的液体高度会变化，这样就能看出比例是不是差不多。闯关的时候有倒计时和分数，也能让玩家知道自己的答题情况。

### 3. 可以自己选择练什么

“趣味数学闯关”现在可以筛选题目。可以选择知识点，也可以选择难度。

这样同学如果哪一块比较薄弱，就可以只练那一块，不用每次都随机做到很多不相关的题。

### 4. 可以多人一起玩

多人联机是我觉得比较有意思的地方。

同学们可以进同一个房间一起答题，最后看排名。这样可以用在课堂上，也可以同学之间互相比赛。

### 5. 后面比较好继续加内容

题库和游戏规则都是分开写的，所以以后想加新题目、新知识点或者新玩法会比较方便。

## 六、还可以继续改进的地方

后面我想继续把“趣味数学闯关”的题库加多一点，让它覆盖更多数学知识。

多人联机也还可以继续改，比如加重新开始、断线重连、历史成绩、错题记录、老师控制房间这些功能。

如果以后时间够，也可以让老师自己上传题目，这样这个作品就不只是小游戏，也可以变成一个更完整的数学练习工具。

## 七、使用方法

### 方法一：直接打开网页

可以直接访问下面三个网址：

- 极速圆周率：https://pandajsr.github.io/MathDamo/#pi-racer
- 调味师大挑战：https://pandajsr.github.io/MathDamo/#flavor-challenge
- 趣味数学闯关：https://pandajsr.github.io/MathDamo/#math-quest

如果网络不好，或者网页打不开，可以用下面的方法。

### 方法二：下载代码运行

先下载安装 Git 和 Node.js。

- Git 官网：https://git-scm.com/
- Node.js 官网：https://nodejs.org/

安装好以后，打开终端，输入：

```bash
git clone https://github.com/PANDAJSR/MathDamo.git
cd MathDamo
npm install
npm run dev
```

然后按照终端里显示的网址打开网页就可以使用。

### 方法三：使用附件里的 Electron 版本

如果不想自己安装和运行代码，也可以使用附件里的 Electron 版本。

下载后直接打开 Windows 的 `.exe` 文件，就可以像普通软件一样使用。这个版本适合不太会用命令行的同学或老师。
